        Diff à merger
        
              
        
                Diff des commits du worktree par rapport à la cible actuelle. Vérifiez de nouveau avant de
                confirmer le merge.
              
        
              
        
              
        
            
        
          
        
        
        
        
        
          
        Préparer le merge avec l’agent
        
          
        
            L’agent du worktree commite les changements voulus, merge la branche cible dans le worktree si
            besoin, résout les conflits et lance les vérifications. Le dossier d’origine n’est jamais modifié,
            aucun push.
          
        
          
          
        
            
            
          
        
        
        
        
        
          Merge fast-forward
          
        
            Le merge exige une cible propre et un fast-forward. Aucune résolution de conflit, aucun push,
            aucun commit automatique.
          
        
          
        
            Seuls les commits du worktree peuvent être mergés. Les changements non commités bloquent le merge.
          
        
          
          
        
            
          
        
        
        
        
        
          Supprimer le worktree
          
        
            Le worktree contient des changements non commités ou non mergés. Cochez la case d’abandon pour les
            écarter explicitement.
